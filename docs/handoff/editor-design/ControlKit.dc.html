Not in the kit, on purpose
No colour, font, font size, padding or pixel setting. Those belong to the theme. A widget that wants emphasis asks for a role (accent, warning, critical), not a colour.

Modifiers any setting can carry
sizes: 4x4
Shown at other sizes but dimmed, with "Only at 4x4." Never hidden: the user learns what a bigger size offers.
when: style = dimmer
Hidden until the condition holds (Control's level reading). For settings that make no sense otherwise.
default: from region | reading | theme
The editor shows where an unset value comes from, as the placeholder or a help line.
label, help, group, order
Plain words from the plugin, localisable. Groups become small headings; more than eight settings fold into Expanders.
